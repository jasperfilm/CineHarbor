# GC Labs 0.4.0 本地版架构升级与创作闭环验收

日期：2026-11-18（Asia/Shanghai）

## 升级范围（1 → 2 → 3 → 4 四阶段）

1. **架构地基与开源标准脱敏**：
   - 剥离仓库内历史短片定制脚本、交付成片与早期调试目录至独立私有归档目录，逐项完成 SHA256 核验；公开源码目录 `runtime/` 仅保留 5 个核心运行时引擎模块。
   - 固化 `vendor/comfy_frontend.zip` 到工程本地缓存，消除 `/tmp` 临时目录重启丢失导致的构建中断。
   - 消除服务端与前端全部个人硬编码路径/项目名；前端引入无状态 `window.GCLabsCore` 传输适配器与结构化 `GCLabsUI` 插槽注册机制，彻底移除 `.replace()` 字符串拼接补丁。
   - `comfy_local_bridge.py` 增加前端静态资源缓存、`/object_info` 元数据缓存（同步写入本地供离线转换复用）及 `/view` 预览文件本地缓存。

2. **分镜与任务能力进化**：
   - 新增原生 Apple Silicon `AVFoundation` 媒体组件 `macos/MediaTool.swift`（`gclabs-media`），零第三方依赖支持媒体探测、精准首/尾帧提取与音视频多轨合成。
   - 分镜画布与检查器支持一键提取已生成视频尾帧/首帧存入素材库，并自动绑定至下一镜头或新建续接镜头。
   - `Console` 支持单次 G4 会话内的多镜头任务顺序排队（`generate_batch` / FIFO 队列）与未执行队列项安全移出，同时保持防重复提交与管理操作互斥。
   - 远端采样接入本地回环 WebSocket `progress` 监听，实时回传采样步数与预计剩余时间；新增 `/api/runtime/interrupt` 安全中断当前采样，不关闭 ComfyUI、不释放 G4 会话。

3. **工作流易用性打通**：
   - 新增 `workflow_converter.py`，支持将 ComfyUI 原始画布 JSON（含 ComfyUI 1.59+ `definitions.subgraphs` 子图、开关节点与数学表达式）在本机直接转换为 API 配方；内置 Wan 2.2 A14B、LTX 2.5 I2V、Qwen Image 2512、ACE-Step 1.5 四套官方模板支持一键载入编辑器。
   - `workflow_library.py` 与 `managed_runtime.py` 新增 `custom_nodes` 锁文件校验与检出（仅允许公开 HTTPS GitHub 仓库 + 固定 40 位小写十六进制 Commit SHA，禁止浮动分支），解除非 H3 工作流对单一节点的硬编码依赖。

4. **多轨粗剪与交付闭环**：
   - 新增 `timeline_export.py` 与 `web/assembly-ui.js`（`▤ 粗剪与交付` 视图），支持按分镜顺序连续联播预览、入出点裁剪与项目配乐/配音同步试看。
   - 支持本机零云端算力一键合成 MP4 粗剪成片、导出 Final Cut Pro / DaVinci Resolve `FCPXML 1.10` 时间线，以及导出自包含剪映 / CapCut 草稿包（`.zip`）。

## 验证结果

- **离线自动化测试**：96 项 Python 单元测试（`test_safety`、`test_console`、`test_gclabs`、`test_workflows`、`test_v040`）全部通过；8 组 Node 界面回归测试全部通过。
- **构建与签名校验**：`GC Labs.app`（`0.4.0`，Build `9`）及 `GC-Labs-0.4.0-arm64-beta.dmg`（`158,567,765` bytes）构建完成，运行期与静态 `codesign --verify --deep --strict` 及 `hdiutil verify` 均校验通过；旧 `0.3.1` App 与旧 DMG 已按规则自动清理。
- **本机原生启动验收**：`/api/health` 与 `/api/capabilities` 返回 `0.4.0` 及 `media_engine: true`；既有 2 个项目与全部受管素材正常读取，HTTP `206` 范围流式读取正常；实时核对余额无消耗（`0` 活动会话，`0.00 CU/hr`）。
