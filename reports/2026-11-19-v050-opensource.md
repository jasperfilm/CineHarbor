# GC Labs 0.5.0 开源正式版功能与安全验收

日期：2026-11-19

## 新增与优化范围

1. **《G4 全精度认证模型一键预设目录》（`model_presets.py`）**
   - 0.5.0 验收时内置 5 套完整精度（BF16 / FP16 / FP32）模型清单：`Wan 2.2 I2V A14B FP16`、`LTX 2.5 22B BF16`、`Qwen Image 2512 BF16`、`ACE-Step 1.5 BF16` 及 `ACE-Step 1.5 XL SFT BF16`。当前 `model_presets.py` 为 6 套，另含 `Qwen Image Edit 2511 BF16`。
   - 一键载入官方画布模板或点击“一键套用”时，自动填充完整精度 `.safetensors` 清单并将节点中的消费级量化权重名（`fp8` / `int8`）升级为完整精度文件名。

2. **CU 预算暂停护栏与手机只读监看（`mobile_monitor.py`）**
   - **CU 预算护栏**：支持设置单次会话最高算力消耗上限（`max_cu_budget`），队列在启动下一项待生成镜头前核对累计消耗，达标自动暂停后续排队任务并保留当前 GPU 会话与已完成资产。
   - **局域网 / Tailscale 手机只读监看**：默认关闭；显式开启时在内存生成一次性随机只读令牌与纯本地 ISO/IEC 18004 SVG 二维码（不调用任何外部二维码接口），仅允许 `GET/HEAD` 读取脱敏状态与实时采样步数，关闭即刻销毁。

3. **角色/场景一致性资产卡（`elements[]`）与多抽卡挑片（`takes[]`）**
   - **角色与场景参考卡**：新增 `✦ 角色与场景卡` 模块，支持定义 `@角色`、`@场景`、`@道具` 固定外观提示词与默认参考图；分镜勾选后在创建任务快照时自动注入一致性描述并继承参考图。
   - **多抽卡挑片（Takes）**：同一分镜多次生成自动归入候选列表，支持一键切换“★ 当前采用版”，粗剪时间线同步跟随当前采用版。

4. **跨平台启动入口与开源 CI**
   - 新增 `gclabs_cli.py`、`pyproject.toml`（支持 macOS / Linux / Windows 本地浏览器模式一键启动）与 `.github/workflows/ci.yml` 双平台自动化测试流水线。
